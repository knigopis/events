# Записи Книгописи

Резервная копия всех записей [Книгописи](https://www.knigopis.com): книги, желания, профили, подписки.
Два раза в день бот забирает события Nostr со всех узлов из `relays.txt` и коммитит снимок.
Записи старой Книгописи (до 2026 года) — в [repo2.knigopis.com](https://github.com/knigopis/repo2.knigopis.com).

## Формат

`events/<первые 2 символа ключа>/<ключ автора>.jsonl` — все записи одного автора, по событию Nostr в строке.

| kind | что |
|---|---|
| 0 | профиль (ник) |
| 3 | подписки |
| 5 | удаление (NIP-09) |
| 10002 | список relay автора |
| 31110 | прочитанная книга: теги `title`, `author`, `read` (`ГГГГ`, `ГГГГ-ММ` или `ГГГГ-ММ-ДД`), заметки в `content` |
| 31111 | желание («прочитать позже»): `title`, `author`, `priority` |
| 31112 | заявка на старый аккаунт: `d` — старый id пользователя |

В снимке — последняя версия каждой записи. Удалённая запись остаётся «надгробием»: та же запись с тегом
`deleted`, без названия и заметок. Прежние версии и удалённое остаются в истории git — **записи публичные,
и история хранит их навсегда.**

## Подлинность

Каждое событие подписано ключом автора. Бот берёт в снимок только события с верной подписью, а узел
при загрузке проверяет подписи снова. Подделать чужую запись не может ни бот, ни узел, ни этот репозиторий.

## Восстановить узел

Из каталога `selfhost` узла ([инструкция](https://github.com/gurov/knigopis-p2p/blob/master/selfhost/README.md)):

```sh
cat /путь/к/events/*/*.jsonl | docker compose exec -T relay /app/strfry import
```

## Предохранитель

Снимок не записывается, а запуск падает (GitHub присылает письмо), если:

- новых событий с прошлого снимка больше 5000 — похоже на спам;
- событий стало меньше на 10% и больше (и хотя бы на 10) — узлы пусты, сломаны или недоступны.

Если всё в порядке (например, много людей разом перенесли старые записи) — Actions → snapshot → Run workflow
с галочкой «force». Пороги — переменные `MAX_NEW` и `MAX_SHRINK_PERCENT` в `snapshot.mjs`.

## Узлы

`relays.txt` — по узлу в строке, тот же список, что `src/known-relays.json` в коде сайта. Недоступный узел
пропускается (это видно в сообщении коммита); если не прочитан ни один, снимок не записывается.

## Локально

```sh
npm ci
npm test               # проверки
node snapshot.mjs      # снимок в events/ здесь
```
